# Programme-d-API-pour-le-contr-le-automatique-du-m-lange-dans-une-cuve
Système automatisé de mélange en cuve : remplissage alterné des matériaux A et B via capteurs de niveau, agitation temporisée, vidange par vanne de sortie, alarme sonore 5 secondes. Contrôlé par API Siemens S7-300 avec verrouillage cycle START/STOP.
